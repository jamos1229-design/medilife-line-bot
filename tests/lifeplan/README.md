# 生存時ライフプラン・資産寿命シミュレーション（初期版）テスト

現在から100歳までの年度別収支・資産・取り崩しを計算する機能を検証する、合成データのみの
テスト群です。実データ・顧客情報・認証情報は一切含みません。

対象コード：`nexus.html`（`n.html`と同一内容）。

## 構成

| ファイル | 内容 | 依存 |
|---|---|---|
| `pure.test.js` | 純粋関数の単体テスト（期間生成・計算エンジン・入力正規化・完了状態判定・二重計上防止） | Node.jsのみ |
| `e2e-planning-sim.test.js` | 画面での入力〜計算結果表示〜保存〜再読込後の保持、iPhone幅での横あふれ確認、既存プランニング機能への無影響確認 | Playwright + ローカルHTTPサーバー |

## 依存関係

- Node.js 18以上
- `pure.test.js`はNode.js標準機能のみで動作し、追加インストール不要です。
- `e2e-planning-sim.test.js`は[Playwright](https://playwright.dev/)を使用し、`tests/dot-bridge/vendor/`配下の
  React本体のローカルコピーをそのまま再利用します（CDNへの依存を避けるため）。本リポジトリの
  `package.json`にはPlaywrightを含めていないため、実行環境に応じて以下のいずれかを用意してください。
  - `npm install -D playwright && npx playwright install chromium`
  - 既にシステム上にPlaywright本体とChromiumがある場合は、`PLAYWRIGHT_CHROMIUM_PATH`環境変数でChromiumの実行ファイルパスを指定できます。

## 実行手順

1. リポジトリのルートで、`nexus.html`を配信するローカルHTTPサーバーを起動します（E2Eテストのみ必要）。
   ```sh
   python3 -m http.server 8792
   ```
   （別のポートを使う場合は、`e2e-planning-sim.test.js`内の`http://localhost:8792/`をあわせて変更してください）

2. 別のターミナルで、リポジトリのルートから各テストを実行します。
   ```sh
   # 純粋関数テスト（Playwright不要）
   node tests/lifeplan/pure.test.js

   # E2Eテスト（手順1のサーバーが起動している状態で実行）
   node tests/lifeplan/e2e-planning-sim.test.js
   ```
   Playwrightパッケージが`node_modules`から解決できない環境では、`NODE_PATH`にPlaywrightのインストール先を追加してください。

3. 各テストは標準出力に`PASS`/`FAIL`を1件ずつ出力し、最後に合計件数を表示します。`FAIL`が1件でもあれば終了コード1で終わります。

## 残る制約（未確認・未実装の範囲）

- 住宅ローンの返済額は「月々返済額」欄が確認済みのものだけを支出として計上します。残高・金利・返済方式からの返済額逆算は今回のバージョンでは行っていません。
- 将来の住宅購入・売却・繰上返済イベント（頭金取り崩し・新規ローン組成等）は今回追加していません。既存の「住宅資金プランニング」とは接続していますが、本格的なイベント計算は対象外です。
- 一時払・全期前納の保険料は、契約日だけで「払込済み」とは判断しません。契約日が基準日以前であり、かつ「保険料の払込状況」が「払込完了」と確認できている場合のみ将来支出から除外します。それ以外（契約日未確認、契約日が基準日より先、または払込状況が未確認）は、支払済みと断定せず未確認として表示します。前期前納は前納期間終了後の払込再開を別途計上します。
- 積立額（savingsItems）は毎年同額として計算します。積立額自体の年次上昇率には対応していません。
- 年齢のみ（生年月日未確認）の顧客は、月単位の切り替わりを反映しない年次の概算になります（画面上に明示）。
- 資産区分は「現金・預貯金／投資信託・株式等／企業型DC／iDeCo／小規模企業共済・国民年金基金／債券／FX／仮想通貨／不動産／その他」の10区分です。保険の貯蓄性資産（解約返戻金相当）・退職金・相続見込（将来受取額）は、受取時期が未確認なため対象資産に含めていません。
- 教育費の進学トラックは、既存の教育資金プランニング機能（`customer.lp.education[kidId].track`）をそのまま再利用します。本機能専用の進学トラック入力は追加していません。
